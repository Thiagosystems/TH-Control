# TH-Control
TH Control: monitor de hardware, perfis de energia e otimizador de internet para Windows. Mostra temperatura, uso e clock de CPU e GPU, RAM, ventoinhas e saúde dos SSDs. Tem perfis Silencioso, Equilibrado e Desempenho com curva de ventoinha, ping ao vivo com jitter e perda, troca e teste de DNS e prioridade de rede para jogos.
